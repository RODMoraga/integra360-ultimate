## 📊 Responsive Behavior Examples

### When window resizes from 1920px → 375px

**1. Branding Column Disappears:**
```
1920px (Desktop):        375px (Mobile):
[Branding] [Form]   →    [Form only]
(50/50 split)            (Full width)
```

**2. Form Max-Width Adjusts:**
```
1920px:  max-width: none (fills available space)
768px:   max-width: 448px (centered container)
375px:   max-width: none, padding: px-6 (edge padding)
```

**3. Typography Scales:**
```
Desktop:  h2: text-3xl, inputs: text-base
Mobile:   h2: text-2xl, inputs: text-sm
```

**4. Button Width:**
```
Desktop:  width: auto, padding: px-8
Mobile:   width: 100% (full width on small)
```

## 🌐 Final Visual Notes

### Design Consistency
- All corners: rounded-lg (8px) or rounded-xl (12px)
- All inputs: 44px+ height (touch-friendly)
- All buttons: 44px+ height (WCAG AA)
- All text: readable size (16px minimum on mobile)

### Spacing System
```
Consistent spacing:
├── XS: 4px
├── SM: 8px
├── MD: 16px  ← Used for most spacing
├── LG: 24px
└── XL: 32px
```

### Shadow System
```
Elevation levels:
├── sm: Subtle shadows (inputs, cards)
├── md: Medium shadows (hovered buttons)
├── lg: Strong shadows (modals)
├── xl: Maximum shadows (hovered cards)
```
